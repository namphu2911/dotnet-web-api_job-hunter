# AI Output Artifacts

This directory stores markdown outputs generated by custom non-code agents.

## Subfolders

- plans: Planning outputs from JobHunter Planner.
- reviews: Code review outputs from JobHunter Reviewer.
- security: Security review outputs from JobHunter Security Reviewer.
- workflows: Workflow summaries from JobHunter Orchestrator.

## File naming

Use: `YYYY-MM-DD-<short-task-slug>-<artifact-type>.md`

Examples:

- `2026-03-16-auth-refresh-plan.md`
- `2026-03-16-auth-refresh-review.md`
- `2026-03-16-auth-refresh-security-review.md`
- `2026-03-16-auth-refresh-workflow.md`
